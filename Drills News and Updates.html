One of the more popular features on Math-Drills is the Math Flash Cards page. As the engine behind it was getting a little outdated, I recently modernized the experience and included some long-needed fixes, mainly to the integers flash cards. Previously there were also fractions and decimals versions, but because they were so under-used and clunky, I decided to retire them.

Following is a description of the recent updates to the whole number flash cards, integers flash cards, the scoreboard and the printing/saving options.

Whole Number Flash Cards

The whole number flash cards allow you to select one to four operations, set a range for each operand, and choose a number of questions. Additionally, you can set “input not required” if you are not interested in the results, such as when you are completing the results orally rather than typing in the answers.

For each additional operation you select, new text displays exactly how each of the operands will be used. For example, if you select all of the operations, the first operand will display: “First Addend Range | Range for Differences (Answers) | First Factor Range | Range for Quotients (Answers).” The second operand will display: “Second Addend Range | Range for Subtrahends (Numbers to Subtract) | Second Factor Range | Range for Divisors.”

As an example, if you wanted to work on dividing by 5, you would select Division from the operations list and uncheck the rest. The first range will be the “Range for Quotients (Answers),” so you would input 1 to 9 or another range depending how far up the times tables you wanted to go. For the second range, you would input 5 to 5. Every question will be a number divided by five with answers in the range 1 to 9.

Most students will likely want both ranges to be the same for general practice. Selecting all the operations and both ranges set to 1 (or 0) to 9 would allow students practice with every single-digit question across all operations.

One of the improvements to the whole number flash cards is a control on the repetition of questions. If your ranges allow for more questions than the number of questions you selected, every question will be different. If your ranges are small, you might see some repetition as the number of possible questions is lower.

Integers Flash Cards

Similar to the whole number flash cards, there is now more descriptive text for exactly what each operand range is for, and repetition is controlled.

One of the most significant updates for the integers flash cards is how the ranges are set. In the past, you would set the lower range as a negative value and the upper range as a positive value (usually), but this meant you were always forced to have 0 in your questions. Because you might not want to include a bunch of zeros in your questions, the ranges are now set as absolute (positive values) and you select whether those values will be mixed (+/-), positive only, or negative only. For example, you can set both ranges to 6 to 12 and select mixed, and you will get questions with only the numbers 6, 7, 8, 9, 10, 11 and 12, either positive or negative. You can’t set both ranges to positive only as that would just make them whole number flash cards!

One of the issues with the old integers flash cards was that you would get a lot of questions with only positive numbers. By default, questions with two positives are turned off, but you can turn it on if you like under the “Integer Types” option.

For those who prefer parentheses, there are two non-default options to have parentheses around negative integers or parentheses around all integers.

Score Board

Two updates to the score board were implemented:

  1. In addition to daily and monthly high scores, there is now an hourly high score board. This might allow students who might not otherwise place in the daily or monthly high scores to place in the hourly high scores.
  2. The score boards always show on the page. Previously, you had to complete a set of questions to see them, but now you can see them at any time.

The theoretical high score is 10,000; however, that would be very difficult to get as it would require using the maximum range (0 to 9999), all operations, 100 questions, and complete each question in one second or less. I was thinking of modifying it slightly to give more weight to students who choose a larger range, so don’t be surprised if it changes in the near future!

Printing/Saving Results

You now have two options (Print or the new Save option) to keep a record of your flash card achievements. Previously, there was only a print option which might have limited some people who didn’t have printers, unless they could figure out how to print to a PDF. When you save the results, you get an .html file which is a simple web document that opens in a browser. Since it is just text, it is small, easy to share, and universally able to be opened on any computer or device.

Privacy

As with other aspects of the website, the flash cards require no registration, no subscription, no paywall, no email address, no hoops! Students are limited to a two-character name that is meant to help them find themselves in the scoreboard and maybe help their teacher identify them. If they save their results, the .html file is created locally by their browser and not saved or uploaded anywhere else. Scores are kept in a database for the purposes of showing them in the scoreboards, but no unrelated data is kept (like IP addresses). Scoreboard data is deleted at the beginning of each month. The flash cards page is ad-free, but you might encounter an ad navigating there.

I hope your students enjoy and learn from the updated flash cards. If you notice any issues or have any comments, please let me know by email at feedback@math-drills.com.
